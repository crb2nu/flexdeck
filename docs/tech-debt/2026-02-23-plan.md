## Wave 1 (Immediate: Stabilization & Guardrails)

- Goal: Close critical security/auth coverage gaps and stabilize repository-wide linting to enable automated verification.
- Items:
  - [TD-008](https://gitlab.flexinfer.ai/services/flexdeck/-/issues/15): Core package test coverage (apiutil, middleware, audit, auth, cluster, rbac).
  - [TD-009](https://gitlab.flexinfer.ai/services/flexdeck/-/issues/16): Repository-wide lint baseline remediation.
- Acceptance criteria:
  - All listed core backend packages have >= 40% statement coverage.

## Wave 2 (Near-Term: Contract & Integration Stability)

- Goal: Tighten API contracts and expand coverage for integration-heavy backend services.
- Items:
  - [TD-005](https://gitlab.flexinfer.ai/services/flexdeck/-/issues/19): API client split and contract tightening.
  - [TD-002B](https://gitlab.flexinfer.ai/services/flexdeck/-/issues/18): Expand tests for `internal/k8s`, `internal/metrics`, `internal/models`.
  - [TD-004](https://gitlab.flexinfer.ai/services/flexdeck/-/issues/21): Shared polling scheduler.

- Acceptance criteria:
  - Large-topology layout benchmark improved by >= 30%.
  - Route registration decentralized into domain modules.
- Risks/mitigations:
