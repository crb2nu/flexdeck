# Tech Debt Implementation Report

## Item

- Debt ID: TD-005
- Branch/PR: `main`
- Owner: gemini-cli

## Problem

- Original pain point: `web/src/lib/api.ts` was a monolithic file centralizing all endpoints and frequently using `any` payloads, making maintenance difficult and masking contract drift.
- Affected components: API client layer.

## Changes

- Summary of refactor/remediation:
  - Split `web/src/lib/api.ts` into a modular structure under `web/src/lib/api/`.
  - Created `client.ts` for the core request engine and multi-cluster logic.
  - Created domain-specific clients: `k8s.ts`, `models.ts`, `agents.ts`, and `infrastructure.ts`.
  - Tightened contracts by using explicit types from `web/src/lib/types.ts` where available.
  - Maintained backward compatibility by re-exporting everything from `web/src/lib/api.ts`.
- Notable design choices:
  - Moved Flux-specific interfaces to `infrastructure.ts` to resolve circular dependency and naming conflicts in `types.ts`.
  - Unified all infrastructure-related APIs (Prometheus, Loki, CI, RBAC, etc.) into `infrastructure.ts`.
